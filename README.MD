This repository contains my Python programming practice and projects.

## Projects

### Student Grade Calculator

A simple Python program that calculates a student's total marks, percentage, grade, and result.

#### Features
- Enter student name and roll number
- Enter marks for 5 subjects
- Calculate total marks
- Calculate percentage
- Display grade
- Display PASS or FAIL
- Validate marks between 0 and 100
- Check minimum marks required in each subject

#### Technologies Used
- Python
- Git
- GitHub

#### How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Go to the project folder:
   `cd student-grade-calculator`
4. Run the program:
   `python grade_calculator.py`
